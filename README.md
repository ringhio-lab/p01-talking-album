# ずかん（talking album）

写真をタップすると、録音した声または入力した文字の声で名前を言う。2歳児と一緒に使うための PWA。

## 使い方

1. iPhone の Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 右上の「**おとなは ここを長押し**」を1秒長押し → おとうさん用の画面がひらく
4. 「写真をえらぶ」で写真を追加し、録音するか「文字から声」で読み上げを作る
5. 録音後は「声のあそび」で、高さ・速さ・話す回数を写真ごとに調整できる
6. 「とじる」で子供の画面へ。写真タップ・どれかなクイズ・自動再生で遊ぶ

## 声のあそび

録音済みの写真ごとに、次の設定を端末内へ保存できる。

- 「そのまま」「ちびっこ」「おおきな声」「ゆっくり」の4プリセット
- 声の高さ（低め〜高め）
- 声の速さ（0.7〜1.35倍）
- 1回・2回・3回の再生パターン

設定はバックアップにも含まれ、以前のバックアップを復元した場合は「そのまま」で再生される。

文字の声には、女性・男性・赤ちゃん・アニメ・ロボットなど8つのプリセットがある。写真は6グループに分類でき、子ども画面で絞り込める。

写真はスマホ向けの大きさへ自動で縮小され、最大30枚まで保存できる。親画面の「バックアップ」で写真・録音・文字の声・分類を1ファイルに退避し、「もどす」で機種変更後も復元できる。

大きく表示された写真は、**どこを触っても閉じる**（2歳児に閉じるボタンは見つけられないため）。

## 個人データはどこにも送信されない

**写真と音声は、この端末の IndexedDB にのみ保存される。**リポジトリにもサーバーにも入らない。

この設計は制約から来ている。GitHub Free では **Private リポジトリで GitHub Pages が使えない**ため、写真をリポジトリに同梱すると配信できない。よって：

- **アプリ本体だけを Public リポジトリに置く**（個人データを一切含まない）
- **写真と音声は端末側**（`<input type="file">` と `MediaRecorder` で取り込み、IndexedDB へ）

結果として、個人データが外に出る経路が構造的に存在しない。`.gitignore` は写真・音声の拡張子を全てブロックしている（アイコンのみ例外）。

## 作りの前提

- **フレームワークなし・ビルドなし。**`index.html` / `app.js` / `sw.js` の3つだけ
- **スマホ専用。**縦向きのiPhone Safari／ホーム画面追加後の利用を主対象にする
- **統制・CI は入れない。**個人の写真アプリに要らない
- オフラインで動く（Service Worker が本体をキャッシュ。写真は元々端末内）

## 既知の制約

- **iOS Safari の `MediaRecorder` は `audio/mp4` を出す**（`webm` ではない）。`pickMime()` で対応する形式を選んでいる
- iOS で音声を鳴らすには**ユーザー操作が必要**。写真のタップがその操作を兼ねているので成立している
- **IndexedDB は iOS に消される可能性がある。**ホーム画面に追加したPWAでは比較的持つが、保証はない。大事な写真の原本は端末の写真アプリに残し、親画面から定期的にバックアップすること
- Service Worker は HTTPS が必須（GitHub Pages で満たす）
